# Animation

Deliver the requested animation, motion design, video, edit or visual asset with usable sources. A design-only brief can finish as an editable composition, storyboard or style frame. Start from audience, purpose, supplied material and destination, including what must remain editable. For existing work, inspect the native project and representative media; improve its limiting factor while preserving useful structure.

## Direct the result

Connect the promise to what the audience sees and hears. Opening, demonstration and ending should belong to the same idea. Choose staging, camera, performance, visual language and sound for the subject. When uncertainty or generic output warrants exploration, compare distinct treatments through small boards, poses or motion beats, then choose and finish. For a costly multi-shot film, test a representative action and its key cut first.

Judge causal progression, contact, spatial continuity and payoff in sequence, not only the strongest still. Preserve a small [continuity reference](references/styles-and-techniques.md#preserve-visual-continuity) for recurring subjects or shot revisions and compare actual adjacent images. Build dynamic progression through visible actions and consequences, with readable holds. Vary emphasis for the material instead of giving every scene the same entrance, pause and exit. A valid export alone does not establish a compelling edit.

## Load the craft and native route needed

Choose tools by quality, control, editability, iteration cost and receiving-system compatibility. Keep native sources at tool boundaries and check the properties that must survive in the actual receiver. Read the applicable reference, rather than the whole production library:

| Work | Reference |
| --- | --- |
| Footage selection, story edit, dialogue, sound, conform or editor handoff | [Editing](references/editorial.md) |
| YouTube idea/script, title/thumbnail, release package, Shorts or channel feedback | [YouTube](references/youtube.md) |
| Dynamic pacing, transitions, causal flowcharts or a static slide-show result | [Purposeful motion](references/purposeful-motion.md) |
| Art direction, animation language, poses or an unfamiliar medium | [Styles and techniques](references/styles-and-techniques.md); [character craft](references/character.md) for character work |
| Local execution, capture versus live time, color/alpha, sound, source bundles or recovery | [Production](references/production.md) |
| 3D/engine work | Available `blender-local` or existing native workflow; [engine choices](references/render-engines.md) |
| Narration/captions or typography | [Voice](references/voice.md), [typography](references/typography.md) |
| A real missing effect, medium, format or control capability | [Discovery](references/discovery.md) |

Match timing to the artifact: offline work needs repeatable evaluation/bakes; interactive work needs explicit input/state and pause/replay behavior. Identify affected shots, takes and dependencies when revising; reuse verified unchanged work.

Inspect final images, cuts, motion, text and sound. For motion or sound judgment, establish that the review route can receive those modalities; use the [review fallback](references/production.md#perceptual-review-and-feedback) when it cannot. Choose relevant checks for duration/frames/sync, loop/alpha, factual claims, input behavior, missing media and receiving-side editability. A sampled frame or technical media check cannot clear unavailable audiovisual judgment.

Deliver the requested masters/assets, native sources, necessary dependencies/terms and concise reproduction/recovery information. Include release assets only when in scope. Preparing drafts does not authorize uploading, publishing, scheduling or contacting anyone. Identify selected masters and material remaining limits in one entry point.

The optional CLI is `scripts/studio.py`. Configuration comes from `ANIMATION_CONFIG`, then private `scripts/local.json`, then `scripts/local.example.json`. [Portable setup](references/portable-setup.md) describes adapter contracts; [historical recipes](references/studio-recipes.md) are dated reproduction detail. Optional `scripts/check_motion.mjs` checks sampled browser seek behavior, not artistic quality. Recheck mutable runtime facts before depending on a retained profile.
